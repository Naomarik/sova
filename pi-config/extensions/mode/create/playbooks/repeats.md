# repeats: running a playbook again by itself

A repeat will be the same card on a schedule, approved by the person's click on exactly what it will run. The card shows Repeat…, which isn't ready yet: don't offer it.

Today a project's playbook runs by itself through an automation file or a schedule (the `automation` topic).

Write playbooks so they can repeat: a run that finds nothing to do says so in a line and ends, and a step that needs the person always stops.

A cycle inside a run and a repeat are the same idea: when it asks the person, when it goes again by itself, and how many times.
