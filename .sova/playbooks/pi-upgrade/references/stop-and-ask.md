# Stop and ask

During the upgrade, stop and ask the user, in this chat, when:

- the boundary baseline would have to grow;
- a new package wants an install script (an `allowBuilds` decision);
- a session version bump the report didn't foresee appears;
- the work turns up anything a person would see or do differently that the plan didn't cover;
- a suite in the queue's `extensions` check fails only because the global pi is still `<terminal>` (a correct fix can use something only `<new>` has). Answer the queue's request with Needs you: the way out is the user's to choose, usually installing the terminal pi just before Land;
- the work turns out much bigger than the plan said: say how much, and why.
