# Find what fails, in real chats

The case finder (`roles/questions.md`) reads where it fails and recent chats like it, and reports the kinds of failure with a count each. You read its report, not the transcripts.

Make the campaign folder now: `<worktree>/.cache/ab/<campaign>/` (a short name: `spec-tool`, `vis-dsl`), with `campaign.json` from your choices (`references/ledger.md`). Check `.cache/` is ignored by Git before anything goes in it.

If the failures turn out to be a bug rather than something a model reads wrong, say so at the next stop: a bug is fixed, not A/B tested.
