# House style for requests

- Titles start with a verb in the imperative ("Add", "Fix", "Show"), name the area first when it helps ("Merge queue: show the host's checks").
- Plain words; a reviewer reads the description in under a minute.
- Lists, not paragraphs, under `## What changes`; each item one line.
- Name files only when a reviewer must look at them first.
- Sections the description must have: `## Why`, `## What changes`, `## Checks`.
