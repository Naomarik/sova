# Local deltas — Sova's skill vs this playbook

The vendored playbook beside this file is a snapshot of rakiba's (see `PROVENANCE.md`), verbatim
except where row 7 says otherwise. This file records the **intentional** divergences between it
and the skill Sova actually ships at `.claude/skills/fold-ai-dev-design/` (rows 1–6), and between
this copy and rakiba's (row 7).

Read it before walking `PARITY.md` item by item: without it, every future audit re-discovers
these as defects and "fixes" one of them back into a state the skill was deliberately moved out
of. Nothing here is an excuse for a defect — each row names the checklist line it diverges from,
what the skill does instead, and the failure the divergence prevents.

## What is *not* a delta

Everything else in this playbook is followed, including the parts the skill got wrong before this
file existed: the heading set and order, `## Marks`, one `Scale & spec` per foundation and brand
reference (nine of nine), `Variants & states` per component (25 of 25), the `is-*` namespace for
demo state helpers, the single-prose-document rule, the ban on a `README.md`, a `CHANGELOG.md`
and inline revision history, and anchored `Rendered:` lines. Licensing is the one mandated
heading deliberately **not** carried — row 6, not an omission.
