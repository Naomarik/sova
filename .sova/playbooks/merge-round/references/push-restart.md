# Merge round: push, restart and report

Steps 6 to 8 of each round. Paths here are relative to the playbook's folder (`references/` is beside `PLAYBOOK.md`).

6. **Push.** `round.mjs push`. On a leak-scan hit, report the commit, file and line it printed, push nothing, and ask the user: waive it, or scrub it (see **Scrub** in `references/traps.md`). A hit the user waives (a name already public, say) is waived for that push only: confirm the scan's hits are exactly the ones waived, run `git push origin master` yourself (never under the push hold, never with a flag), and name it as waived in the report. Ask again each time a hit comes back.
7. **Restart**, when `start` or `restart-check` says the live server is behind master: its head lacks master's runtime code, whoever merged it (`landed` says so too). `round.mjs restart-check`. A session that has claimed the restart keeps it: leave it and say so. Busy sessions never hold it: every chat, worker and reply runs in a process of its own and keeps running through a restart. Run the restart line it printed (`systemctl --user restart <unit>`; on macOS `launchctl kickstart -k gui/<uid>/<label>`); if it fails, ask the user. The next `start` confirms it: report the head it came back on.
   Then `curl -s 127.0.0.1:4800/api/health`: `head` must be master and `startedAt` after the restart.
8. **Report.** `round.mjs report`, filled in: what was handed back and why, and on a first round the settings' kinds and counts and names already public on origin (masked, as printed). Branches with no live owner are in it once, the first time they are the user's call, each with the typed OK that lands it. Branches whose Landing card Sova showed and that wait for the user are listed as `report` prints them: the owner's chat by its title, with its link, and that "land it" typed there does the same; never "its card is showing" alone, and never a card Sova didn't show. A quiet round (nothing asked, checked, landed or pushed, and nothing new for the user) is one line, exactly as `report` prints it: "Nothing new on the merge board."
