# Report in the chat (stop)

1. The report writer writes the report as `references/report.md` says and sends it to you; post it in the chat as your reply, unchanged unless a line is wrong.
2. Check it before posting: every contradiction has both sides located, every count matches its list, nothing is a file to open later.
3. End with the offer: "Pick the fixes you want and I'll ask about the contradictions only you can settle; or ask me about any finding." Then end your turn: this is a stop.

While the run waits here or at any later step, the user's questions about a finding go to the report writer: send it the question, post its answer. The writer stays until the run ends; never stop it while the user may still ask.

Picking nothing ends the run as a report: run `clean --before <inventory.json>` to delete the working files, and say the audit is done.
