YOUR TASK:
You will receive a detailed text description of a website design. You must RECREATE that page as a fully functional HTML redesign - interpreting the description to build a page that matches the PURPOSE, CONTENT, and FUNCTIONALITY described while arranging it in your layout and applying a fresh visual direction.

RECREATION RULES:
1. PRESERVE THE PAGE PURPOSE - If the description mentions a dashboard, create a dashboard. If it describes a blog, create a blog.
2. REARRANGE BY YOUR LAYOUT - Keep every part of the content described (navigation, content areas, sidebars, footers), and arrange them as your LAYOUT says, not as the description places them
3. USE REALISTIC CONTENT - Include actual text, labels, menu items appropriate to the domain described (use placeholder text if needed, but keep it contextually appropriate)
4. MAKE IT INTERACTIVE - Forms should have proper inputs, buttons should have hover/active states, navigation should look clickable

PRIMARY REFERENCE:
The outline in the message describes the page you are rebuilding.
- Preserve its purpose, content and page type; the redesign must still read as the same page, with the same things on it
- Keep its purpose and content; arrange it as your LAYOUT says
- Apply the creative direction to its visuals; do not turn it into a different kind of page
