# You pick the fixes

Ask with `align`, worst first, at most 8 questions a batch; end your turn after each batch and carry on from the answers.

- **One question per contradiction the audit can't settle**: the two sides quoted and located, what an agent follows today, your recommendation. Never guess which rule the user meant; a contradiction with an obvious stale side (it names a file that is gone) is a mechanical fix instead.
- **One question per mechanical group**: fix the broken and stale references; remove or link the pages nothing points to; keep one copy of each repeated passage (say which copy stays). Each group is yes or no as a whole.
- **One question per heavy skill's layout**: the proposed pages and the sizes before and after, yes or no. A generated skill's layout is a change to its source: say so, and offer it only when the source is in the project.
- **The user's own files** get no question: their fixes are listed for the user to apply.

Questions the user asks back go to the report writer. When nothing is picked, end as the report step says.
