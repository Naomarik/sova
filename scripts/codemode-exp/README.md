# codemode turns experiment

`run.mjs` measures how the `codemode` minor mode changes a model's turns, tool calls, tokens and wall time
on one small, read-only, automatically graded task. Results: `docs/perf/2026-10-06-codemode-turns.md`.

Each run: a fresh copy of a 17-file fixture repo (generated by the script) becomes the cwd of a new web
session; the model is set (default `zai/glm-5.3`), then the minor modes (`POST /api/mode?path=` with
`minorModes: []` or `["codemode"]`), then one prompt goes out over `/ws/chat` (wire 2). After `run.settled`
the script reads the session JSONL, records the metrics, grades the final `ANSWER` block against the key
and archives the session. Arms run interleaved, rotating which goes first:

- `off`: codemode off.
- `on`: codemode on, same prompt.
- `hint`: codemode on, and the prompt ends with one sentence asking for the codemode tool.

## Rerun

Use a hermetic agent dir with only a zai login, and a server of your own (never the live 4800):

```sh
HERMETIC_AGENT_DIR=$PWD/tmp/codemode-exp/agent node scripts/hermetic-agent-dir.mjs
node -e 'const a=require(process.env.HOME+"/.pi/agent/auth.json");require("fs").writeFileSync("tmp/codemode-exp/agent/auth.json",JSON.stringify({zai:a.zai}),{mode:0o600})'
PORT=4814 PI_CODING_AGENT_DIR=$PWD/tmp/codemode-exp/agent scripts/start-server.sh &
node scripts/codemode-exp/run.mjs --port 4814 --agent tmp/codemode-exp/agent --runs 6
```

Flags: `--runs N` (per arm), `--arms off,on,hint`, `--model`, `--runs-dir` (fixture copies; default
`$TMPDIR/sova-codemode-exp`), `--out` (default `docs/perf/data/codemode-turns`), `--timeout-s`,
`--retries` (a run whose model call errors, or that times out, is retried after 30 s), `--keep-sessions`
(don't archive). `--summarize <dir>` prints the table again from saved `run-*.json` files.

Keep the runs dir outside any tree that has an `AGENTS.md` or `CLAUDE.md` above it: pi loads every such
file from the cwd up to `/`, so a fixture under this repo would add Sova's `CLAUDE.md` (~16k tokens) to
each prompt.

## Output

`run-<stamp>-<i>-<arm>[-retryN].json` per attempt: `turns` (assistant messages after the prompt),
`toolCalls` / `byTool` (top level), `codemodeCalls`, `nestedCalls` / `nestedByTool` (the codemode results'
`details.calls`), `usage` (summed over assistant messages; `input` is uncached), `wallMs` (prompt sent →
`run.settled`), `grade`, the final text and each codemode script. `summary-<stamp>.json`: per-arm stats and
every attempt, failed ones included.
